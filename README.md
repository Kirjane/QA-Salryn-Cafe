# Salryn Cafe · Kirjane Labs QA Portal

This repository owns the **non-technical human QA portal** for Salryn Cafe, independently of the engineering codebase.

- QA instruction portal: staged on `qa/portal-maintainer` for review before launch.
- Windows installer and Android APK URLs: intentionally **not published** until reviewed QA artifacts exist.
- Vercel: deployment **requires explicit Technical Authority approval**. No Vercel integration or automatic deployment is authorized by this commit.
- No authentication, password protection, access encryption, or tester account required to read the published instructions.
- Do not upload credentials, personal data, database copies or customer information to this public repo.

The separate QA maintainer owns portal content and issue triage, not Salryn Cafe product code, production deployment or financial acceptance.
